# os-install —— 系统安装，以及跨越安装边界的契约

*中文 · [English](README.md) · 返回 [仓库 README](../README.zh.md)*

关于**安装**操作系统，以及那些「因为两套系统共用同一台机器」才存在的东西。

## 归属规则

| 主题属于 | 放在哪 |
| :--- | :--- |
| 只属于某一个系统（Windows 的一项设置、Linux 的一个包） | [`../windows/`](../windows/) 或 [`../linux-desktop/`](../linux-desktop/) |
| 安装本身（分区、引导器、首次启动顺序） | 本目录 |
| 两套已安装系统之间的**契约** —— 两边必须一致的那一个值 | 本目录 |

第二、三行正是这个目录值得单独存在的原因。契约从任何一边看都是隐形的：每个系统单独看
都自洽，差异只有开机进另一个系统时才暴露，而固件里不会记录这个选择。**这种契约必须写
下来**，否则它只会以 bug 的形式被重新发现。

## 本目录的约定

- **英文优先。** `x.md` 是给 agent 用的基准，`x.zh.md` 是给人参考的直接翻译。
- **`files/` 里的脚本不修改任何东西。** 它们只读取状态并报告。所有修复都是操作者主动
  执行的命令，并且写在与之一旁的正文里，紧挨着支撑它的实测数据。
- **不含真实标识符。** 主机名、用户名、IP 一律用占位符，见 [`../redaction.zh.md`](../redaction.zh.md)。
- **文件名与所有配置文件纯 ASCII**，含注释；行尾 LF。见 [`../conventions.zh.md`](../conventions.zh.md)。
