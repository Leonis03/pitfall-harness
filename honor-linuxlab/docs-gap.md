## 六个 C 类缺口

### 5. 删除桌面数据 —— 官方只有禁令，没有 SOP

官方两处强调"不得把删除桌面数据作为普通故障排查步骤"，但没说之后怎么恢复。
本仓库 skill §5 已有完整流程（Intent 注入打包 → 校验 → 重置 → 一行 `tar -xf` 还原）。

### 7. 无法输入中文 —— 官方只到"按 Ctrl+空格"

见 [`README.md`](README.md) 2.2 与 2.3 节。官方排查终点是"确认有输入光标 + 按 `Ctrl+空格`"，
既不知道 fcitx5 活动组首项必须是拼音，也不知道触发键本身可能被 Android 宿主截胡。

2026-09-30 那次故障已确诊，两条叠加：`profile` 的活动组首项是 `keyboard-us` 而非 `pinyin`；
以及缺少全局 `config` 导致只能用出厂的 `Ctrl+Space`，而这个键在实体外接键盘上被 MagicOS
当成系统语言切换。**与 locale 无关**——locale 改动发生在故障报出 20 分钟之后，
只是因为随后用户来仓库里问"设英文会不会导致输入法失效"，才让两者看起来像因果。

照官方那份排查做完（按 Ctrl+空格），故障不会好。这正是 C 类缺口的定义。

### 15. 文件中转目录 —— 官方映射不完整

官方只说"我的平板文件夹在 Linux 中是 `/tablet`"。本仓库 skill §1.1 是双向表。
2026-10-14 实测：容器内 `/sdcard` **根本不存在**（`No such file or directory`），
只有 `/tablet`。官方没写这层区分，容易让人在容器里 `cd /sdcard` 然后困惑。

### 17. Linux 桌面无法联网 —— ★最高价值缺口

见 [`README.md`](README.md) 2.1 节。官方整节方向是"确认平板本身能联网"，
知识库里 `proxy` 与 `http` 命中均为 **0**——终端代理变量这一层完全不存在。

2026-10-10 实测：平板网络正常、桌面浏览器正常、APT 源直连正常，
但 pnpm/npm 全挂在 `tunnel error`。根因是 shell 配置导出的代理变量指向无人监听的端口。

2026-10-14 追加发现：故障分**死代理**（配置遗留，端口 refused）与**活代理**（运行时注入，
端口有监听、请求 200）两类，不能混谈。注入方**未确诊**。

官方那句"不要填写来源不明的代理地址"方向没错，但它默认读者已知终端变量这层的存在——
读者不知道，于是要么全清（可能砸掉可用路径），要么全留（继续踩死代理）。

### 20. Linux 桌面没有声音 —— 官方零提的真实诱因

官方只让用户检查平板媒体音量。本仓库记了一个官方完全没提的诱因：**卸载 snapd 时连锁清掉了
`pulseaudio`**，导致容器与 Android 宿主之间的音频桥接断掉。这类"清理动作引发的连锁损坏"
是官方答疑范式覆盖不到的。

### 26. 安全边界 —— 官方通用，本仓库具体

官方红线是通用的"别删数据、别改容器文件"。本仓库 skill §1.2 给的是可执行的具体禁令
（`pm clear`、未备份不得点删除桌面数据、ADB shell UID 进不去私有目录）。

## 两个 D 类：官方说法需要标注差异

### 2. 资源更新失败 —— 排查方向可能误导

官方让用户先确认"平板本身能联网"。但资源下载走 Android 网络栈，**不读 shell 环境变量**，
与终端里的 npm/pnpm 是两条网络路径。官方把用户引向"检查平板网络"对终端侧故障无效。
应补一句边界，不要否定官方。

### 25. 无法直接读取当前设备状态 —— 已经过时 ★

官方单元写的是"使用答疑知识库不能直接读取当前设备的安装、网络、更新或键盘状态"。
但 2026-10-14 实测：**该助手有 Bash**，能读 `/data/user/0/com.hihonor.pcengine/`、
能读 `/proc/mounts`、能跑网络探测命令。知识库播种于 2026-09-23，此后 bot 已带上一整套
执行工具，**知识库与 agent 实际能力已经脱节**。

影响：以后引用官方说法要标注采集日期，不能默认它描述的是当前能力。

## 不该做的（15 个 A 类）

第 1、3、6、8–14、16、18、22、23、27 号单元官方都写到了操作层且正确，重写只会制造第二真相
来源并带来同步负担。**其中第 27 号（交流群号、设备 SN 查询路径）本仓库按脱敏规则不记录**。

值得单独说的是第 6–13 号这一整节"输入与控制"：官方 8 个单元全部覆盖，本仓库此前基本空白。
历史上调查过"Debian 侧蓝牙键盘调起 Android 软键盘"，但那批结论**没有沉淀**，且当时
agent 已提示"那边有 jsonl 记录吗"——原始记录可能在别的机器上。这是待回收的素材，
不是当前缺口。
